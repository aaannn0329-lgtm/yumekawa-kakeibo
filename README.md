# ゆめかわ家計簿 ♡

わんこといっしょにつける、スマホ用のゆめかわ家計簿です。
HTML / CSS / JavaScript だけで動き、データはスマホの中（localStorage）に保存されます。

## いまできること
- **ホーム**：今月の残り予算・使用率バー・連続記録日数・クレカ/銀行/現金別の支出・カテゴリ別円グラフ・きょうの記録一覧
- **記録する**：支出/収入の切り替え、金額、よく使うボタン（追加・編集・削除OK）、カテゴリ、支払い方法、メモ
- 右上の ⚙︎ から月の予算を変更
- わんこの表情とセリフが予算の状況で変わります（予算内→にっこり／ペース速め・オーバー→こまり顔）

## ファイル
| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | デザイン |
| `app.js` | 動き・データ保存 |
| `manifest.json` / `sw.js` | ホーム画面に追加・オフライン対応 |
| `images/` | わんこ画像（normal / smile / sad） |
| `icons/` | アプリアイコン |

## スマホのホーム画面に追加する
ホーム画面への追加とオフライン対応には **https** での公開が必要です。かんたんなのは GitHub Pages です。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Branch で公開したいブランチと `/ (root)` を選んで Save
3. 表示された URL をスマホで開く
   - **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
   - **Android（Chrome）**：メニュー → 「ホーム画面に追加」／「アプリをインストール」

> データはそのスマホ・そのブラウザの中だけに保存されます。ブラウザのデータを消すと記録も消えるので注意してね。

## パソコンで試す
```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 更新したとき
`sw.js` の `CACHE_NAME` の数字（`v1` → `v2`）を上げると、スマホ側も新しい版に切り替わります。
