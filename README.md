# yumekawa-kakeibo

ゆめかわ家計簿 — 白いわんこと一緒に、毎月の予算を守るための家計簿アプリ。

## できること

- **現金の予算**：月初に決めた額だけATMでおろす。おろした額をきろくして、予算をこえるとわんこがしょんぼり。
- **現金の使い道メモ**：ランチ・コンビニ・飲み会・美容院などを選んでメモ。「手元にあるはずの現金」もわかる。
- **服・買い物の予算**：月の上限に対して、今の使いすぎペースを表示。
- **家族の生活費グラフ**：固定費・食費・光熱費・通信費・日用品・その他を月ごとに積み上げグラフと円グラフで表示。
- **バックアップ**：JSONで書き出し・読み込み。

## データについて

入力したデータは、使っているブラウザ（localStorage）の中だけに保存され、どこにも送信されません。
このリポジトリには家計のデータは入っていません。

## 使い方

`index.html` をブラウザで開くだけで動きます。GitHub Pages で公開すると、スマホのホーム画面に追加してアプリのように使えます。
